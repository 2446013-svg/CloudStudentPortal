Cloud Student Portal

A Simple Cloud-Based Web Application

About the Project

Cloud Student Portal is a simple web application designed to demonstrate cloud computing concepts such as accessibility, scalability, and basic security.

Accessibility

The application can be accessed through a public HTTPS URL from different devices and locations.

Scalability

The application is designed as a stateless web service that can run on multiple cloud instances.

Security

Helmet security middleware, HTTPS deployment, environment variables, and Git protection are used.
